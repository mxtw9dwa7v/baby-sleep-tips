# 吃甲泼尼龙片副作用有哪些

> 更新时间：2026-09-15 (UTC+8)

长期或大量服用甲泼尼龙片可能出现代谢紊乱、、免疫抑制、精神症状、、青光眼和白内障、生长等副作用，特殊人群需特别注意，如有不适或疑问应及时告知医生。

1.代谢紊乱：长期使用甲泼尼龙片可能导致血糖升高、、钠水潴留和等。

2.消化性溃疡：糖皮质激素可能刺激胃酸分泌，增加和的风险。

3.免疫抑制：长期使用可能抑制机体的免疫功能，增加感染的风险，特别是在使用剂量较高或存在免疫缺陷的情况下。

4.精神症状：部分患者可能出现焦虑、抑郁、、兴奋等精神症状。

5.骨质疏松：长期使用糖皮质激素可能导致骨质疏松，增加的风险。

6.青光眼和白内障：长期使用可能增加眼压，导致青光眼的发生，还可能影响晶状体代谢，引发白内障。

7.生长发育迟缓：儿童长期使用可能影响生长发育。

需要注意的是，这些副作用并非一定会发生，且个体对药物的反应可能存在差异。在使用甲泼尼龙片期间，医生会密切监测患者的身体状况，并根据具体情况调整剂量或采取相应的预防措施。

此外，对于特殊人群，使用甲泼尼龙片需要特别注意：

儿童：长期使用可能影响生长发育，应尽量避免长期使用。如需使用，应密切监测身高、体重等生长指标。

老年人：老年人更容易出现骨质疏松、感染等副作用，使用时应谨慎，并适当补充钙剂和维生素D。

孕妇和哺乳期妇女：期间应避免使用甲泼尼龙片，除非有明确的适应证。哺乳期妇女使用时，应注意药物对婴儿的影响。

如果正在服用甲泼尼龙片或其他药物，出现任何不适症状，应及时告知医生。同时，应遵循医生的建议，按时服药，并注意饮食、锻炼和生活方式等方面的调整，以提高治疗效果和减少副作用的发生风险。如果对药物的使用有任何疑问，可与医生进行充分的沟通。
